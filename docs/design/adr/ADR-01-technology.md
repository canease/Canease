# ADR-01: Use HTML, CSS, and JavaScript

- **Status:** Proposed
- **Date:** November 3, 2026
- **Decision:** Build CyberHelp with HTML, CSS, and JavaScript and publish it with GitHub Pages.
- **Context:** CyberHelp is a simple informational website. It does not need user accounts, a database, or live support.
- **Alternatives considered:** A larger web framework or an application with a backend and database.
- **Reason for decision:** Plain HTML, CSS, and JavaScript are enough for the planned features and keep the project simple to build and maintain.
- **Requirements supported:** R1, R2, R3, R7, R9
