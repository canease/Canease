# ADR-03: Use Clearly Labeled Topic Sections

- **Status:** Proposed
- **Date:** November 3, 2026
- **Decision:** Present topic information using clear sections for the problem description, warning signs when available, and recommended steps.
- **Context:** Users need to understand the problem and know what actions they can take.
- **Alternatives considered:** Showing the information as one block of text or using unlabeled lists.
- **Reason for decision:** Separate headings make the information easier to scan and help users find the recommended steps.
- **Requirements supported:** R4, R5, R6
