# ADR-02: Organize Information by Categories and Topics

- **Status:** Proposed
- **Date:** November 3, 2026
- **Decision:** Let users browse CyberHelp by selecting a category and then a topic.
- **Context:** The project is intended to help people find beginner-friendly cybersecurity and technical information without searching across many websites.
- **Alternatives considered:** A keyword search interface or a long page containing every topic.
- **Reason for decision:** Category and topic browsing gives the information a clear structure and lets users move through it one step at a time.
- **Requirements supported:** R1, R2, R3, R7, R11
